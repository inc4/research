# INC4 Research

Published research from [INC4](https://inc4.net), an engineering studio that builds software and AI for complex systems.

We don't write papers about things we haven't built. Every paper here is backed by production systems and open-source code.

---

## Papers

### InKH — Interaction-Native Knowledge Harness (2026)

**Absorbing Complexity: An Interaction-Native Knowledge Harness for Financial LLM Agents**

Converts user, market, portfolio, and tool events into structured operational knowledge using passive injection, temporal graph memory, and audit surfaces. 0.815 task quality at 900ms latency — 82.95% faster than agent-driven alternatives.
- [Paper on arXiv](https://arxiv.org/abs/2606.01886)
- [Details & BibTeX](./InKH/)

### SAE — Survivability-Aware Execution (2026)

**Execution Is the New Attack Surface: Survivability-Aware Agentic Crypto Trading with OpenClaw-Style Local Executors**

A middleware layer for agent-based crypto trading that enforces execution safeguards — exposure budgets, rate limits, slippage bounds — reducing max drawdown by 93.1%.

- [Paper on arXiv](https://arxiv.org/abs/2603.10092)
- [Code: SAE Policy Guard](https://github.com/true-ai-labs/sae-policy-guard)
- [Details & BibTeX](./SAE/)
