# InKH — Interaction-Native Knowledge Harness

## Absorbing Complexity: An Interaction-Native Knowledge Harness for Financial LLM Agents

## Abstract

Financial AI agents often fail for a simple reason: they make users carry the complexity. InKH converts user, market, portfolio, and tool events into structured operational knowledge using passive injection, temporal graph memory, and audit surfaces.

**Key results** (synthetic benchmark, 46,080 evaluations):
- Task quality: **0.815**
- Latency: **900ms** — 82.95% reduction vs agent-driven alternatives
- Traceability improvement: **+0.461**
